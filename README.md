## Dashboards de Vendas

## Nome do Projeto

    Dashboards de Vendas

## Sobre o Projeto

    . Projeto desenvolvido para ajudar na visualização de dashboards, onde temos o faturamento do mes, faturamento por tipo de produto, faturamento por filial, faturamento por tipo de pagamento, avaliação. Na aplicação poderemos selecionar também o mes dos faturamentos.

## Conhecimentos

    . Python
    . Excel

## Conceitos

    . Bibliotecas
        . streamlit
        . pandas
        . plotly.express

## Preparando o ambiente

    . Instalar Visual Studio Code
    . Instalar Bibliotecas

## Rodar projeto

    . streamlit run .\dashboards.py
